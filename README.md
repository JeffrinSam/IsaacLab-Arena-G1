# Isaac-Lab Arena - G1 Loco-Manipulation (Working Version)

**A scalable environment creation and evaluation framework for robotics simulations built on top of NVIDIA Isaac Lab**

**This is a working version with fixes and improvements for G1 Loco-Manipulation workflow with GR00T N1.5 policy.**

</div>

Isaac-Lab Arena is a comprehensive robotics simulation framework that enhances NVIDIA Isaac Lab by providing a composable, scalable system for creating diverse simulation environments and evaluating robot learning policies. The framework enables researchers and developers to rapidly prototype and test robotic tasks with various robot embodiments, objects, and environments.

## What's Included in This Repository

This repository contains a **working version** of IsaacLab-Arena with the following improvements:

- ✅ **Critical Fixes**: Pinocchio import order issue resolved
- ✅ **Docker Improvements**: Missing dependencies added, PYTHONPATH configured
- ✅ **G1 Loco-Manipulation**: Complete workflow with GR00T N1.5 policy
- ✅ **Comprehensive Documentation**: AI agent memory, fixes, workflow guides
- ✅ **Evaluation Scripts**: Ready-to-use scripts for policy evaluation
